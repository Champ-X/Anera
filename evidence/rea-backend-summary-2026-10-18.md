## 实际修复

| 机制 | 修复前本地复现 | 当前实现 |
|---|---|---|
| 输入受理与重试 | 相同初始 UUID 并发两次：2 个会话、2 次 mock 模型执行 | 初始输入身份与会话创建一起落盘；普通输入收据与 `pendingStart` 同一次原子状态写入。并发同 ID 请求合并；已接受的同 ID、同意图返回原会话/turn；不同意图返回 HTTP 409。 |
| 不确定回执 | 页面重试生成新 ID；历史刷新失败也可能看似提交失败 | 页面保留未确认输入 ID；内容、附件、模型、连接器或 review 目标变化才换 ID。HTTP 或规范快照中的 `turn.started.clientMessageId` 确认后释放。创建成功后的历史刷新独立处理。 |
| 未启动输入恢复 | 受理落盘后发布状态失败，可能永久停在 queued/running | 保留原收据、重建启动事件并转为 interrupted；故障持续时保留恢复日志。存储恢复后的重试在启动预留保护下修复无运行所有者的状态；进程重启也可恢复。重试不重新派发模型，用户可 Continue。 |
| 定向停止 | 上一轮的停止请求晚到，取消正在执行的新轮 | 停止请求绑定 `targetInputId` / `targetTurnId`；同时提供时均须匹配。保护启动预留到运行的转换与异步查询后的所有权。旧目标/已结束目标不操作；终态不会被改回 cancelling。 |
| 语音片段调度 | 工具契约允许独立片段并行，实际 peak concurrency 为 1 | 连续独立语音片段按配置上限并行；同一规范化输出路径串行；与其他工具保持屏障，结果顺序稳定。 |
| 语音配额与用量 | 重复工具 ID 可能合并不同调用的额度；交付失败可能丢用量 | 按 step + callIndex 识别调用次数，持久预留保留每轮 10 次上限。取消或文件提交失败仍保留已发生用量；隔离共享取消异常，避免后续未执行调用继承前次用量。既有幂等结算避免重启重复累计。 |

受理收据只保存私有摘要与 turn ID，不进入公开快照或模型上下文。Undo / 工作区恢复保留已接受身份；用户有意重新执行需新的输入 ID。损坏的收据拒绝执行，不能被当作“尚未接受”。

| Approval / HITL | 保留明确授权、调用身份与恢复边界；历史一次未出现审批不构成移除审批的依据。 |
| 模型输出取消 | 保留迟到回调门控，并增加停止请求本身的目标检查。 |

## 边界

- 本地后端设计针对当前单写入进程；没有实现多服务器共享数据库锁，也不宣称远程模型调用在崩溃场景下 exactly-once。
- 输入身份索引目前来自持久 session state 扫描；任一损坏状态会阻止新建以避免重复受理。大型数据集可再引入带恢复校验的索引。
- 兼容旧调用者：未传 `clientMessageId` 的普通消息仍使用原提交行为；当前 Agent 页面已传稳定 ID。Coding repository 创建流程不在本轮幂等改造范围。
- 页面草稿/未确认 attempt 仍仅保存在页面内存；没有新增跨刷新草稿存储。服务端收据本身跨重启保留。
- 原子 rename 与恢复日志验证的是进程中断恢复，不是断电 fsync 保证。独立语音并行是对可见工具契约的本地实现，不是 Arena 私有调度器的复刻声明。
- 同路径队列保护正常执行顺序；已有工具超时包装层提前返回后，已进入的持久化文件提交仍可能继续。本轮没有增加覆盖这种后台执行余项的跨超时锁。
